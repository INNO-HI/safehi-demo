# Requirements Checklist: 상세 페이지 (002-admin-dashboard)

## 돌봄 일지 상세 페이지 (/care-logs/[id])

- [ ] **FR-030**: 돌봄 일지 목록에서 행 클릭 시 상세 페이지로 라우팅
- [ ] **FR-031**: 상단 헤더에 대상자명, 상태 배지, 작성일시 표시
- [ ] **FR-032**: 방문 정보 섹션 (방문 일시, 유형, 담당 매니저, 소속 센터)
- [ ] **FR-033**: 돌봄 내용 카드 (건강/식사/정서/생활환경)
- [ ] **FR-034**: 특이사항 섹션 표시
- [ ] **FR-035**: 첨부 사진 썸네일 그리드 및 라이트박스 확대
- [ ] **FR-036**: 대기중 상태일 때 승인/반려 버튼 표시
- [ ] **FR-037**: 반려 사유 입력 모달
- [ ] **FR-038**: "목록으로" 버튼으로 목록 페이지 이동

## 대상자 상세 페이지 (/recipients/[id])

- [ ] **FR-039**: 대상자 목록에서 행 클릭 시 상세 페이지로 라우팅
- [ ] **FR-040**: 상단에 대상자명, 나이, 성별, 상태 배지, 아바타 표시
- [ ] **FR-041**: 기본 정보 카드 (주소, 연락처, 비상 연락처, 담당 매니저)
- [ ] **FR-042**: 건강 정보 카드 (질환, 약물, 특이사항)
- [ ] **FR-043**: 최근 방문 요약 (최근 3건)
- [ ] **FR-044**: 네비게이션 버튼 (전체 방문 기록, 담당자 메모, AI 정책 추천)
- [ ] **FR-045**: "목록으로" 버튼으로 목록 페이지 이동

## 담당자 메모 페이지 (/recipients/[id]/memos)

- [ ] **FR-046**: 메모 목록 최신순 정렬 표시
- [ ] **FR-047**: 각 메모에 작성자명, 작성일시, 내용 표시
- [ ] **FR-048**: "메모 추가" 버튼 및 입력 폼
- [ ] **FR-049**: 메모 저장 시 목록 상단에 추가
- [ ] **FR-050**: "돌아가기" 버튼으로 대상자 상세 이동

## 방문 기록 페이지 (/recipients/[id]/visits)

- [ ] **FR-051**: 방문 기록 타임라인 형식 표시
- [ ] **FR-052**: 각 기록에 방문일시, 유형 아이콘, 담당자, 요약 표시
- [ ] **FR-053**: 기록 클릭 시 돌봄 일지 상세 페이지 이동
- [ ] **FR-054**: 날짜 범위 필터 기능
- [ ] **FR-055**: "돌아가기" 버튼으로 대상자 상세 이동

## AI 복지 정책 추천 페이지 (/recipients/[id]/policies)

- [ ] **FR-056**: 추천 정책 적합도순 정렬 표시
- [ ] **FR-057**: 정책 카드 (정책명, 지원 내용, 적합도, 신청 방법)
- [ ] **FR-058**: 정책 카드 클릭 시 상세 정보 표시
- [ ] **FR-059**: "새로고침" 버튼으로 추천 갱신
- [ ] **FR-060**: "돌아가기" 버튼으로 대상자 상세 이동

## 공통 요구사항

- [ ] **FR-061**: Mock 데이터 구현 (하드코딩 금지)
- [ ] **FR-062**: 커스텀 훅 구현 (useCareLogDetail, useRecipientDetail, useMemos, useVisits, usePolicies)
- [ ] **FR-063**: TypeScript 타입/인터페이스 정의
- [ ] **FR-064**: 데이터 로딩 중 스켈레톤 UI
- [ ] **FR-065**: 에러 메시지 및 재시도 버튼

## User Story 검증

### US6: 돌봄 일지 상세 조회
- [ ] 목록에서 행 클릭으로 상세 이동
- [ ] 방문 정보 섹션 확인
- [ ] 돌봄 내용 카드 표시
- [ ] 특이사항 확인
- [ ] 첨부 사진 확대 기능
- [ ] 승인 처리
- [ ] 반려 처리 (사유 입력)

### US7: 대상자 상세 정보 조회
- [ ] 목록에서 행 클릭으로 상세 이동
- [ ] 기본 정보 확인
- [ ] 건강 정보 확인
- [ ] 최근 방문 요약 확인
- [ ] 서브 페이지 네비게이션

### US8: 담당자 메모 관리
- [ ] 메모 목록 조회
- [ ] 새 메모 작성
- [ ] 메모 저장 후 목록 갱신

### US9: 방문 기록 전체 조회
- [ ] 타임라인 형식 표시
- [ ] 날짜 필터 적용
- [ ] 기록에서 일지 상세 이동

### US10: AI 복지 정책 추천 조회
- [ ] 정책 목록 표시
- [ ] 정책 상세 확인
- [ ] 새로고침 기능

## Edge Cases

- [ ] 존재하지 않는 ID 접근 시 404/에러 처리
- [ ] 데이터 로딩 중 스켈레톤 표시
- [ ] 네트워크 오류 시 재시도 버튼
- [ ] 사진 없는 일지 처리
- [ ] 메모 없는 경우 빈 상태
- [ ] 방문 기록 없는 경우 빈 상태
- [ ] 추천 정책 없는 경우 안내 메시지
