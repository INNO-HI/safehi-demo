# Feature Specification: 설정 페이지 (Admin Settings)

**Feature Branch**: `005-admin-settings`
**Created**: 2026-02-19
**Status**: Draft
**Input**: 관리자 대시보드의 설정 페이지 구현 - 피그마 UI 기반으로 프로필, 계정정보, 알림설정, 시스템설정, 관할구역, 계정관리 섹션을 포함하는 설정 페이지

## Overview

SafeHi 관리자 대시보드의 설정 페이지는 구/군 관리자가 자신의 계정, 알림 환경설정, 시스템 설정, 관할 구역 정보를 한 곳에서 확인하고 관리할 수 있는 중앙 설정 허브이다. 40~60대 사용자를 주 대상으로 하므로 큰 글씨, 직관적 레이아웃, 최소한의 조작으로 설정을 변경할 수 있어야 한다.

기존 대시보드, 돌봄 일지, 대상자 관리, 매니저 관리, 통계/리포트 페이지와 동일한 레이아웃(사이드바 + 헤더)과 디자인 시스템을 유지하며, 기존 UI 컴포넌트(Card, Button, Input, Select 등)를 재활용한다.

**디자인 참조**: 피그마 UI 시안 제공됨 (첨부 이미지 참조)

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 내 프로필 및 계정 정보 확인 (Priority: P1)

구/군 관리자가 설정 페이지에 진입하여 자신의 프로필(이름, 역할, 이메일, 전화번호, 가입일)과 계정 정보를 한눈에 확인한다. 필요 시 이름, 연락처, 이메일을 개별적으로 변경할 수 있다.

**Why this priority**: 관리자가 자신의 계정 정보를 정확히 확인하고 변경하는 것은 설정 페이지의 가장 기본적인 기능이다. 잘못된 연락처나 이메일은 업무 소통에 직접적인 영향을 준다.

**Independent Test**: 설정 페이지에 접근하여 프로필 정보가 올바르게 표시되는지, 각 필드의 "변경" 버튼이 동작하는지 확인하면 독립적으로 테스트 가능하다.

**Acceptance Scenarios**:

1. **Given** 로그인된 관리자가 사이드바에서 "설정"을 클릭했을 때, **When** 설정 페이지가 로드되면, **Then** 좌측에 프로필 카드(이니셜 아바타, 이름, 역할 배지, 이메일, 전화번호, 가입일)가 표시된다.
2. **Given** 설정 페이지에서 프로필 카드를 확인 중일 때, **When** "수정" 버튼을 클릭하면, **Then** 프로필 편집 모드로 전환되어 정보를 수정할 수 있다.
3. **Given** 설정 페이지 우측에 계정 정보가 표시될 때, **When** 이름 필드의 "변경" 버튼을 클릭하면, **Then** 이름을 수정할 수 있는 입력 필드가 활성화된다.
4. **Given** 계정 정보에서 비밀번호가 표시될 때, **When** 페이지가 로드되면, **Then** 비밀번호는 "●●●●●●●●" 형태로 마스킹 처리되어 표시된다.

---

### User Story 2 - 알림 설정 관리 (Priority: P1)

관리자가 업무 관련 알림(새 보고서, 긴급 케이스, 주간 리포트, 이메일 알림)의 수신 여부를 토글 스위치로 개별적으로 켜고 끌 수 있다. 모바일 푸시 알림 안내 배너도 함께 표시된다.

**Why this priority**: 돌봄 업무에서 긴급 케이스 알림은 어르신 안전과 직결되며, 관리자가 알림 수신 여부를 직접 제어할 수 있어야 한다. 프로필과 동일한 P1으로 분류한다.

**Independent Test**: 알림 설정 섹션의 4개 토글 스위치를 각각 ON/OFF 전환하고, 상태가 올바르게 변경되는지 확인하면 독립적으로 테스트 가능하다.

**Acceptance Scenarios**:

1. **Given** 설정 페이지의 알림 설정 섹션이 표시될 때, **When** 페이지가 로드되면, **Then** 4개의 토글 스위치가 가로로 배열되어 표시된다 (새 보고서: ON, 긴급 케이스: ON, 주간 리포트: ON, 이메일 알림: OFF).
2. **Given** "이메일 알림" 토글이 OFF 상태(회색)일 때, **When** 토글을 클릭하면, **Then** ON 상태(파란색)로 전환되고 설정이 저장된다.
3. **Given** 알림 설정 섹션 하단에, **When** 모바일 푸시 알림 배너가 표시될 때, **Then** "safehi 앱에서 실시간 알림을 받으세요" 메시지와 "앱 다운로드" 버튼이 보인다.

---

### User Story 3 - 시스템 설정 변경 (Priority: P2)

관리자가 시스템 환경설정(언어, 시간대, 다크 모드, 자동 새로고침)을 자신의 업무 환경에 맞게 조정할 수 있다.

**Why this priority**: 시스템 설정은 업무에 직접적인 영향은 적지만, 사용자 경험과 편의성을 높이는 기능이다.

**Independent Test**: 시스템 설정 섹션에서 각 드롭다운과 토글을 변경하고, 변경 사항이 반영되는지 확인하면 독립적으로 테스트 가능하다.

**Acceptance Scenarios**:

1. **Given** 시스템 설정 섹션이 표시될 때, **When** 언어 드롭다운을 클릭하면, **Then** 사용 가능한 언어 목록(한국어가 기본 선택)이 표시된다.
2. **Given** 시간대 드롭다운이 표시될 때, **When** 기본값을 확인하면, **Then** "(GMT+9) 서울"이 선택되어 있다.
3. **Given** 다크 모드 토글이 OFF 상태일 때, **When** 토글을 클릭하면, **Then** ON으로 전환된다.
4. **Given** 자동 새로고침 토글이 ON 상태일 때, **When** 설명 텍스트를 확인하면, **Then** "대시보드 자동 갱신 (5분)"이 표시된다.

---

### User Story 4 - 관할 구역 정보 확인 (Priority: P2)

관리자가 자신의 관할 구역 정보(소속 기관, 담당 동 수, 복지센터 수, 소속 매니저 수)를 확인하고, 담당 동 목록을 열람할 수 있다.

**Why this priority**: 관할 구역 정보는 읽기 전용으로 확인하는 기능이며, 업무 범위를 파악하는 데 도움이 된다.

**Independent Test**: 관할 구역 섹션에서 기관 정보, 통계 카드, 동 목록이 올바르게 표시되는지 확인하면 독립적으로 테스트 가능하다.

**Acceptance Scenarios**:

1. **Given** 관할 구역 섹션이 표시될 때, **When** 페이지가 로드되면, **Then** 기관명("서울특별시 양천구")과 부서 정보("어르신복지과 · 돌봄 서비스팀")가 아이콘과 함께 표시된다.
2. **Given** 통계 카드 영역이 표시될 때, **When** 3개의 통계 카드를 확인하면, **Then** 담당 동(18), 복지센터(12), 소속 매니저(156)가 각각 카드 형태로 표시된다.
3. **Given** 동 목록이 표시될 때, **When** 목록을 확인하면, **Then** "목동1동, 목동2동, ... 외 11개 동" 형태로 요약 표시되고, "전체보기" 버튼이 제공된다.

---

### User Story 5 - 계정 관리 (로그아웃, 비밀번호 변경, 문의) (Priority: P3)

관리자가 세션 종료(로그아웃), 비밀번호 변경, 계정 관련 문의를 수행할 수 있다. 이 섹션은 빨간 테두리로 시각적 주의를 환기시킨다.

**Why this priority**: 로그아웃과 비밀번호 변경은 보안 기능이지만 자주 사용되지 않으며, 계정 문의는 외부 연동이 필요하다.

**Independent Test**: 계정 관리 섹션의 3개 액션 버튼이 올바르게 표시되고 클릭 시 적절한 동작을 수행하는지 확인하면 독립적으로 테스트 가능하다.

**Acceptance Scenarios**:

1. **Given** 계정 관리 섹션이 빨간 테두리와 함께 표시될 때, **When** 3개 액션을 확인하면, **Then** 로그아웃("실행" 버튼, 빨간색), 비밀번호 변경("변경" 버튼, 파란색), 계정 문의("문의" 버튼, 테두리)가 각각 표시된다.
2. **Given** 로그아웃 영역에서, **When** "실행" 버튼을 클릭하면, **Then** 확인 대화상자가 표시되고, 확인 시 로그아웃되어 로그인 페이지로 이동한다.
3. **Given** 비밀번호 변경 영역에서, **When** "변경" 버튼을 클릭하면, **Then** 비밀번호 변경 화면 또는 모달이 표시된다.
4. **Given** 계정 문의 영역에서, **When** "문의" 버튼을 클릭하면, **Then** 문의 양식 또는 관리자 연락처 정보가 제공된다.

---

### Edge Cases

- 네트워크 연결이 끊긴 상태에서 설정을 변경하면, 사용자에게 오류 메시지를 표시하고 변경 사항을 롤백한다.
- 다른 세션에서 동일 계정의 정보가 변경된 경우, 현재 세션에서 최신 정보를 반영한다.
- 필수 필드(이름, 이메일)를 빈 값으로 변경하려 할 경우, 유효성 검사 오류를 표시한다.
- 이메일 형식이 올바르지 않을 경우, 적절한 오류 메시지를 표시한다.
- 전화번호 형식이 올바르지 않을 경우(숫자가 아닌 문자 입력 등), 적절한 오류 메시지를 표시한다.
- 비밀번호 변경 시 현재 비밀번호가 틀린 경우, 명확한 오류 메시지를 표시한다.
- 토글 변경 후 저장에 실패한 경우, 토글을 이전 상태로 복원하고 오류를 알린다.

## Requirements *(mandatory)*

### Functional Requirements

**페이지 구조**

- **FR-001**: 설정 페이지는 경로 `/admin/settings`에서 접근 가능해야 한다.
- **FR-002**: 페이지 상단에 제목("설정")과 부제("계정, 알림, 시스템 설정을 관리합니다")가 표시되어야 한다.
- **FR-003**: 페이지 하단에 푸터("INNO-HI Inc. | 최종 업데이트: 2026.02.19 | © 2026 INNO-Hi. All rights reserved.")가 표시되어야 한다.
- **FR-004**: 기존 사이드바, 헤더 레이아웃을 그대로 사용해야 한다.

**내 프로필 섹션**

- **FR-005**: 좌측 프로필 카드에 이니셜 원형 아바타, 이름, 역할 배지("구/군 관리자"), 이메일, 전화번호, 가입일이 표시되어야 한다.
- **FR-006**: 프로필 카드 상단에 "수정" 버튼이 제공되어야 한다.
- **FR-007**: 이니셜 아바타는 사용자 이름의 첫 2글자를 원형 배경 위에 표시해야 한다.

**계정 정보 섹션**

- **FR-008**: 우측 계정 정보 섹션에 4개 필드(이름, 연락처, 이메일, 비밀번호)가 표시되어야 한다.
- **FR-009**: 각 필드에는 개별 "변경" 버튼이 제공되어야 한다.
- **FR-010**: 비밀번호 필드는 "●●●●●●●●" 형태로 마스킹 처리되어야 한다.
- **FR-011**: 변경 버튼 클릭 시 해당 필드가 편집 가능한 상태로 전환되어야 한다.

**알림 설정 섹션**

- **FR-012**: 전체 폭 섹션에 4개의 토글 스위치가 가로로 배열되어야 한다.
- **FR-013**: 각 토글은 제목과 설명을 함께 표시해야 한다: (1) 새 보고서 알림 - "매니저가 새 보고서 제출 시", (2) 긴급 케이스 알림 - "긴급 상태 발생 시 즉시", (3) 주간 리포트 알림 - "매주 월요일 요약 발송", (4) 이메일 알림 - "중요 알림 이메일 수신".
- **FR-014**: 토글 ON 상태는 파란색(#3b82f6) 배경, OFF 상태는 회색(#e2e8f0) 배경으로 표시되어야 한다.
- **FR-015**: 토글 변경 시 즉시 설정이 저장되어야 한다 (별도 "저장" 버튼 없이).
- **FR-016**: 모바일 푸시 알림 배너가 하단에 표시되어야 하며, "safehi 앱에서 실시간 알림을 받으세요" 메시지와 "앱 다운로드" 버튼을 포함해야 한다.

**시스템 설정 섹션**

- **FR-017**: 좌측에 시스템 설정 섹션이 표시되어야 하며, 4개 항목을 포함해야 한다.
- **FR-018**: 언어 설정은 드롭다운으로 제공되며, 기본값은 "한국어"이다.
- **FR-019**: 시간대 설정은 드롭다운으로 제공되며, 기본값은 "(GMT+9) 서울"이다.
- **FR-020**: 다크 모드 설정은 토글 스위치로 제공되며, 기본값은 OFF이다.
- **FR-021**: 자동 새로고침 설정은 토글 스위치로 제공되며, 기본값은 ON이고, 설명 "대시보드 자동 갱신 (5분)"이 함께 표시되어야 한다.

**관할 구역 섹션**

- **FR-022**: 우측에 관할 구역 섹션이 표시되어야 한다.
- **FR-023**: 기관 정보(아이콘, 기관명 "서울특별시 양천구", 부서 "어르신복지과 · 돌봄 서비스팀")가 표시되어야 한다.
- **FR-024**: 3개의 통계 카드(담당 동, 복지센터, 소속 매니저)가 숫자와 라벨로 표시되어야 한다.
- **FR-025**: 담당 동 목록이 요약 형태("목동1동, 목동2동, ... 외 N개 동")로 표시되어야 한다.
- **FR-026**: "전체보기" 버튼 클릭 시 전체 동 목록을 확인할 수 있어야 한다.

**계정 관리 섹션**

- **FR-027**: 전체 폭 섹션이 빨간 테두리로 시각적 주의를 환기시켜야 한다.
- **FR-028**: 3개 액션이 가로로 배열되어야 한다: (1) 로그아웃 - "실행" 버튼(빨간색), (2) 비밀번호 변경 - "변경" 버튼(파란색), (3) 계정 문의 - "문의" 버튼(테두리).
- **FR-029**: 로그아웃 실행 시 확인 대화상자를 표시한 후 세션을 종료하고 로그인 페이지로 이동해야 한다.
- **FR-030**: 각 액션에는 설명 텍스트가 함께 표시되어야 한다 (로그아웃: "현재 세션에서 로그아웃합니다", 비밀번호 변경: "보안을 위해 주기적으로 변경하세요", 계정 문의: "관리자에게 계정 관련 문의하기").

**접근성**

- **FR-031**: 모든 텍스트는 최소 12px, 본문 14px 이상이어야 한다.
- **FR-032**: 모든 클릭/터치 영역은 최소 44x44px이어야 한다.
- **FR-033**: 텍스트 대비율은 WCAG AA (4.5:1) 기준을 충족해야 한다.
- **FR-034**: 토글 스위치, 버튼 등 모든 인터랙티브 요소에 적절한 접근성 레이블이 제공되어야 한다.

**데이터**

- **FR-035**: 초기 구현은 Mock 데이터를 사용하며, 추후 백엔드 API로 교체할 수 있도록 데이터 계층을 분리해야 한다.
- **FR-036**: 설정 변경 사항은 클라이언트 상태에 즉시 반영되어야 한다.

### Key Entities

- **UserProfile**: 관리자의 프로필 정보를 나타냄. 이름, 역할, 이메일, 전화번호, 가입일, 이니셜 아바타 정보를 포함한다.
- **AccountInfo**: 계정 인증 정보를 나타냄. 이름, 연락처, 이메일, 비밀번호(마스킹)를 포함하며, 각 필드는 개별 수정 가능하다.
- **NotificationSettings**: 알림 환경설정을 나타냄. 새 보고서 알림, 긴급 케이스 알림, 주간 리포트 알림, 이메일 알림의 ON/OFF 상태를 포함한다.
- **SystemSettings**: 시스템 환경설정을 나타냄. 언어, 시간대, 다크 모드, 자동 새로고침의 설정값을 포함한다.
- **JurisdictionInfo**: 관할 구역 정보를 나타냄. 기관명, 부서, 담당 동 목록, 복지센터 수, 소속 매니저 수를 포함한다. 읽기 전용 데이터이다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 관리자가 설정 페이지에 진입한 후 3초 이내에 모든 프로필 및 설정 정보를 확인할 수 있다.
- **SC-002**: 관리자가 알림 토글을 변경하는 데 1회 클릭(터치)으로 완료할 수 있다.
- **SC-003**: 관리자가 계정 정보(이름, 연락처, 이메일) 변경을 30초 이내에 완료할 수 있다.
- **SC-004**: 40~60대 사용자가 별도 도움 없이 원하는 설정을 찾아 변경할 수 있다 (직관적 레이아웃).
- **SC-005**: 설정 페이지의 모든 인터랙티브 요소가 WCAG AA 접근성 기준을 통과한다.
- **SC-006**: 기존 페이지(대시보드, 돌봄 일지 등)와 시각적으로 일관된 디자인을 유지한다.

## Assumptions

- 백엔드 API가 아직 구현되지 않았으므로, Mock 데이터로 먼저 구현하고 추후 교체한다.
- 다크 모드 토글은 UI만 제공하며, 실제 다크 모드 테마 적용은 이 feature 범위에 포함되지 않는다.
- "앱 다운로드" 버튼은 외부 앱 스토어 링크를 연결하거나 placeholder로 구현한다.
- 계정 문의 기능은 이메일 링크(mailto) 또는 간단한 안내 팝업으로 구현한다.
- 관할 구역 정보는 읽기 전용이며, 관리자가 직접 변경할 수 없다.
- 언어 설정은 현재 한국어만 지원하며, 드롭다운 UI는 제공하되 다국어 전환 기능은 향후 확장 사항이다.
- 프로필 이미지 업로드 기능은 없으며, 이니셜 기반 아바타만 사용한다.
- 비밀번호 변경 시 현재 비밀번호 확인, 새 비밀번호 입력, 새 비밀번호 확인의 3단계 프로세스를 따른다.
